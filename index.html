Create a Room

Host a private two-player match in three short steps.

01 Choose a game Select the game you want to host.
02 Create a room The platform creates a private invite code.
03 Invite a friend Share the code so another player can join.
↗

Have an invite code?

Room codes connect you to a private two-player match. Make sure you and your friend are using the same game version.

Codes are not case-sensitive. Spaces and dashes are ignored.

PRIVATE BY DESIGN

No public room list

This platform only uses private two-player rooms. A room can be joined only through the invite code shared by its host — there is nothing to browse.
